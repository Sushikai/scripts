## R002 — Y01 N 字战法抓首板 ⚠️
**原话**:`今日涨幅 9.5~10% (首板) ∧ 近 5 日存在一次涨停 ∧ 近 5 日最低价未破首板阳线实底 ∧ 当前价 ≥ 首板次日最高价 ×0.99`
**代码** (`yeren_backtest.py:286-288`):
```python
ok = streak in (1, 2) and sr_pass and not any("拉萨" in s for s in seats)
```
- ✅ `streak in (1,2)` 覆盖"首板/二板"
- ⚠️ **缺失**:近 5 日二次涨停检查 (用 streak 而非历史 5d 涨停计数)
- ⚠️ **缺失**:最低价未破前低检查 (要 `dims["first_zt_low"]`)
- ⚠️ **缺失**:当前价 ≥ 首板次日最高 ×0.99 (要 `dims["second_break_high"]`)
- **结论**:**实现 = 简化版**, 仅"连板数+封成+非拉萨"三筛,漏 2/4 的 N 字几何条件
- **风险**:误判 — 把"纯涨停+封成"当 N 字抓,真实 N 字战法应该是"先有涨停→回踩→再封板", 现在只判第二次

## R003 — Y02 封死优先 ⚠️
**原话**:`当日涨停封板时间 < 14:30 ∧ 封单/成交 > 10% ∧ 未炸板`
**代码** (`yeren_backtest.py:289-298`):
```python
es = (hh < 14) or (hh == 14 and mm < 30)
ok = sr_pass and burst == 0 and es
```
- ✅ 首封时间 < 14:30
- ⚠️ **偏差**:`sr_pass = seal > 30 if seal <= 100 else seal > 300` — 不是原话的"封单/成交 > 10%"
- ⚠️ **缺失**:burst_count 来自 AKShare `zt_pool`, 但 Y02 还要"未炸板"语义, `burst==0` 等价, OK
- **结论**:**封成比阈值偏离原话**,原话 10%, 实现 30%/300% (≈ 真实封成比 1σ 之外), 会漏判
- **修复**:把 sr_pass 阈值改 `seal_ratio_pct > 10` 或保留 30 但加注"实战更严"

**代码** (`yeren_backtest.py:302-304`):

- **优先级**:P0, 必须修
