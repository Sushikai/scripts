## 1. 妖股的定义 (市场共识)

**核心定义**: 短期内股价脱离基本面、出现异常波动的个股 — 基本面无实质利好却连续涨停、波段大涨。

| 维度 | 量化口径 (多来源共识) |
|---|---|
| 连板 | "三板成妖", 5 板以上为核心妖股; 历史大妖 9-15 板 |
| 波段涨幅 | 5 个交易日涨幅 ≥50%; 成妖全程 3-8 倍 |
| 换手率 | 成妖期间日换手 >20% (高位换筹常见 20-65%) |
| 市值 | 启动时 <100 亿, 50 亿左右最密集; 流通盘小 |
| 价格 | 启动前多在 10 元以下, 5 元左右最密集 |
| 唯一性 | 每轮行情约 1-2 个月出一只, 与大盘情绪周期绑定 |
| 环境 | "弱市出大妖" — 多诞生于大盘相对弱/混沌期, 避险资金抱团 |

**妖股 = 情绪 + 资金 + 题材共振, 与基本面无关**; 必然经过充分换手(烂板)由分歧走向一致, 后期纯筹码博弈。

## 2. 妖股 vs 龙头 vs 连板股

- **连板股**: 连续涨停 ≠ 妖股, 大量连板只是跟风/补涨品种
- **龙头股**: 领涨 + 带动板块, 可以不是连板形态(趋势龙头); 有板块梯队
- **妖股**: 情绪更强的龙头, 空间高度最大; **不需要小弟、不依赖板块**, 独立走强; 高位缩量加速连板
- 关系: 妖股一定是龙头, 龙头未必是妖股

## 3. 生命周期与阶段特征

| 阶段 | 时长 | 可量化特征 | 可操作性 |
|---|---|---|---|
| 0 蛰伏期 | 数月-数年 | 底部横盘、均线粘合、成交低迷、低价小市值 | 不可抓(等待) |
| 1 启动期 | 1-2 板 | 首板放量换手、烂板(分歧)、二板定龙头; 低位突破 | ★ 抓 (二板分歧转一致打板, 胜率参考 88%) |
| 2 主升期 | 3-5 板 | 换手板接力、缩量加速、不破 5 日线 | ★★ 抓 (打板/低吸, 断板即走) |
| 3 加速/末期 | 6+ 板 | 高位缩量连板、封单变小、炸板变多 | ☆ 仅持筹 (禁追高) |
| 4 见顶 | 1-3 日 | 高位爆量烂板、放量阴线、断板、跟风集体跌停 | 卖 (首阴/断板离场) |
| 5 退潮 | — | 断板确认走完、核按钮、3-5 日收盘 <20 日线 | 空仓 (断板反包仅限缩量首阴) |

**口诀**: 分歧买, 一致卖, 加速跑, 见顶核; 断板即走不留情。

## 4. 介入战法 (阶段 → 买点)

| 战法 | 标的 | 买点 | 风险 |
|---|---|---|---|
| 首板试错 | 新题材低位首板 | 打板, 轻仓 | 大部分淘汰 |
| 二板分歧转一致 | 首板烂板+放量, 竞价高开5%+快速上板 | 封板瞬间打板 | 中 |
| 打板接力 | 2-3 板分歧转一致 | 回封/确认打板 | 高 |
| 首阴低吸 | 3-5 板换手龙(仅第一次阴线) | 分时急杀/尾盘/次日低吸 | 中 |
| 断板反包 | 缩量首阴 + 不破 5 日线/前高 | 反包确认 | 高 |
| 禁: 高位加速板、6+板追高、破位死扛 | | | |

## 5. 情绪周期指标 (抓妖的环境开关)

| 指标 | 阈值 | 含义 |
|---|---|---|
| 涨停家数 | >80 高潮, <30 极弱 | 情绪温度 |
| 晋级率 (昨连板今再板) | ≥60% 强化, <40% 警惕 | 赚钱效应延续性 |
| 1进2 晋级率 | 走低=退潮, 回升=修复 | 最敏感分层 |
| 炸板率 | <20% 极强, 20-40% 正常, >50% 很差 | 打板成功率 |
| 连板高度 (空间板) | 突破压制=新周期, 断崖=退潮 | 周期位置 |
| 梯队断层 | 有5板缺3-4板 | 高位悬空风险 |
| 赚钱效应中位 | 涨停40家中位-1.8%=退潮, 25家中位+4%=健康 | 真实体感 |
| 龙头断板 | 总龙头断板=退潮核心信号 | 卖出信号 |

**应用**: 妖股识别只在晋级率≥40% + 炸板率<50% + 空间板≥3 的环境下启用(避免冰点期空转)。

## 6. 回测机制设计 (核心 · 与 ZT 同口径可比)

妖股页的抓取信号必须有回测验证支撑 — 设计原则: **与 zt_backtest 真实路径完全同口径**, 所有历史统计直接可比。

### 6.1 执行口径 (与 ZT 一字不差)
- **买入**: 信号日 T 收盘确认 → T+1 开盘价买入
- **一字板**: T+1 开盘==最高(容差 0.3%) → 空仓, 0 收益
- **成本**: 双边 0.66% (滑点 0.2% + 买入费 0.03% + 卖出税 0.1% + 卖出费 0.03%)
- **真实账户**: top_n 只等权 (mult=1/top_n), 按日叠加; 也输出 per-trade 口径

### 6.2 介入点 (信号 → 可配置)
| 信号 | 买入时机 | 语义 |
|---|---|---|
| 2板确认 | 2板收盘后次日开盘 | 二板定龙头 |
| 3板确认 | 3板收盘后次日开盘 | 三板成妖 |
| 4板确认 | 4板收盘后次日开盘 | 主升确认 |
| 断板低吸 | 断板当日收盘 (或次日开盘) | 首阴/断板反包 (调研证伪, 仅对比用) |

### 6.3 退出规则 (可配置, 默认妖股铁律)
| 规则 | 说明 |
|---|---|
| break_close (默认) | 断板日收盘卖出 — "断板即走"铁律 |
| hold_n | 持有 N 个交易日 |
| ma5_stop | 收盘破 5 日线卖出 |
| stop_loss | 硬止损 (-5%/-8%) |

### 6.4 环境闸门 (情绪周期过滤)
- 每日计算: 涨停家数 / 晋级率 (昨日涨停今日仍涨停比例) / 空间板高度
- 闸门: 涨停家数 ≥30 且 晋级率 ≥25% 才允许开仓 (按历史分位校准, 可配置)
- 输出按闸门开/关分组的收益对比, 验证闸门有效性

### 6.5 指标输出
- 总览: 交易数 / 胜率 / avg / 累计 / 最大回撤 / 盈亏比 / 一字板空仓率
- 分组: 按介入连板数 (2/3/4/5+) · 按月 · 按环境 (闸门开/关)
- 对比: 与 ZT baseline 同窗口同口径并排

### 6.6 实现
- `yaogu_backtest.py` 独立模块 (参照 zt_backtest.py 结构: 候选事件 → 模拟 → 聚合)
- 事件缓存 /tmp/yaogu_events.json: 首次构建 ~200s, 之后秒级 (支撑 1000 轮迭代)
- 前端: 妖股页内嵌回测面板 (同 ZT 页的 scenario 模式)

## 6b. 历史样本统计分析 (2020-01 ~ 2026-08 · 3627 只 · 27263 连板段)

### 6b.1 连板段分布 (妖股数量稀少, 有稀缺性)
| 连板数 | 段数 | 占 2板+ 比例 |
|---|---|---|
| 2 | 3222 | 59.1% |
| 3 | 864 | 15.9% |
| 4 | 403 | 7.4% |
| 5 | 192 | 3.5% |
| 6+ | 170 | 3.1% (大妖 9-18 板共 50+ 段) |

**6年半仅 1639 段妖股候选 (≥3板 或 段涨幅≥50%), 涉及 1036 只** — 每月约 20 段, 真妖 (6板+) 每月约 2 段。

### 6b.2 启动特征 (段首前一日)
- 启动前收盘价: 中位 8.83 元, P25 5.23 / P75 15.00 — **印证"10 元以下小盘启动"**
- 换手率/市值: SQLite 无填充 (1.6%), 无法历史统计 — 页面用实时数据补

### 6b.3 真实路径介入模拟 (T+1开盘买 + 一字板空仓 + 0.66% 成本 · 持有到断板收盘卖)
| 介入点 | 交易数 | 一字板空仓率 | 胜率 | avg/笔 | 累计 |
|---|---|---|---|---|---|
| **2板后** | 3410 | **41.7%** | 42% | **+0.52%** | **+1788.8%** |
| 3板后 | 1038 | **56.3%** | 44% | +1.20% | +1243.7% |
| 4板后 | 474 | **61.2%** | 41% | +0.48% | +225.7% |
| 断板日收盘买→次日卖 | 1616 | 0% | **34%** | **-2.91%** | **-4709%** |

**关键结论**:
1. **断板低吸 (首阴战法) 是亏钱的** — 胜率 34%, avg -2.91%。市场流行的"首阴战法/断板反包"在裸历史口径下是负期望, 页面抓取规则必须排除。
2. **介入越早越好**: 2板介入期望最优; 3/4 板介入的单笔 avg 更高但空仓率飙升 (56-61%), 实际能买到的机会急剧减少。
3. **一字板空仓是最大摩擦**: 越到高位越买不进 (2板 42% → 4板 61%), 与 ZT 教训 (27.3%) 同构, 但更严重。
4. **分板段条件胜率** (2板介入后最终走到 N 板): 3板 60% / 4板 92% / 5板 100% / 6+ 100% — 说明"持有到断板"纪律下, 走出来的妖股贡献主要收益; 但 2板介入有 59% 的票断在 2板 (负期望)。
5. **情绪环境**: 涨停家数中位 27 (P25 13 / P75 51); 晋级率中位 21.9% — 环境闸门阈值需按此校准 (高晋级率日占比约 25-30%)。

## 7. 妖股识别模型设计 (v2 · 经 6b 统计校准)

### 7.1 候选池
- 当日涨停池 (涨停阈值: 主板 9.5% / 创科 19.5%)
- 连板 ≥2 (启动期 2-3 板) — **不做断板低吸/首阴反包** (6b.3 证明负期望)

### 7.2 妖性评分 (0-100, 6 维 · 经统计校准)
| 维度 | 权重 | 口径 | 统计依据 |
|---|---|---|---|
| 连板高度 | 25 | 2板=30, 3板=45, 4板=60, 5板=75, 6+=85 | 2板介入期望最优, 高度加分但仍支持 2 板抓 |
| 量能活跃 | 20 | 成交额/20日均量 ≥1.5 倍=20, 1-1.5=12, <1=5 | 一字缩量板买不进 (空仓率 42-61%) |
| 市值弹性 | 15 | 实时市值 <60亿=15, 60-100=10, 100-200=5, >200=2 | 启动前收盘价中位 8.8 元 (6b.2) |
| 资金强度 | 20 | 龙虎榜游资席位 + 净流入 (顶级游资=满) | 调研 2: 资金接力是成妖前提 |
| 题材热度 | 10 | 当期主线题材 / 新题材 | 调研 1: 题材驱动 |
| 情绪环境 | 10 | 涨停家数≥30 + 晋级率≥25% 折算 | 6b.3: 中位 27 家 / 21.9% 晋级率 |

### 7.3 阶段分类 (基于 6b 统计的硬规则)
| 阶段 | 判定 | 操作 |
|---|---|---|
| 启动 | 连板 2 (首板放量, 二板确认) | ★ 抓取 (最优介入点) |
| 主升 | 连板 3-5, 尚未断板 | ★ 抓取 (3板空仓率 56%, 机会少但 avg 高) |
| 加速/末期 | 连板 ≥6 | 仅监控 (空仓率 61%+, 禁追) |
| 断板 | 当日未涨停 (前一日涨停) | 卖出信号 (持有者断板即走) |
| 退潮 | 断板 + 环境闸门关闭 | 空仓 |

### 7.4 抓取规则 (v2)
- **信号 1: 2板确认** — 连板 2, 二板放量换手, 环境闸门开 → "明天 09:30 可买" (对标 ZT 推票模式)
- **信号 2: 3板主升** — 连板 3, 封板质量好, 闸门开 → 同上
- **卖出规则: 断板收盘卖出** (唯一默认, 6b.3 验证)
- **环境闸门**: 涨停家数 ≥30 且 晋级率 ≥25% (按 6b.3 分位校准, 可调)
- **禁: 断板低吸 / 首阴 / 断板反包** — 34% 胜率负期望, 页面标注为"非抓取信号"

### 7.5 评分示例 (页面展示)
- 妖性分 ≥70: 核心妖股 · ≥50: 妖股候选 · <50: 观察
- 阶段标签: 启动/主升/加速/断板 · 环境标签: 闸门开/关
