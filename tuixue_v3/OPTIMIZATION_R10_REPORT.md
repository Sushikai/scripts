## 二、第 2 轮 · server.py 健壮性与超时加固

**目标**：所有上游调用加显式超时 + 永不静默挂起。

### 改动
- 全局 `safe_call(timeout)` 助手，封装 `asyncio.wait_for` + 异常分类（ConnectError / Timeout / 5xx / 其他）
- 行情端点统一 `asyncio.gather(*, return_exceptions=True)`，单个上游失败不影响整体
- 25s 超时落到兜底 (`{"degraded": True, "reason": ...}`) 而不是 500
- 给核心端点加 `Cache-Control: max-age=2` 与 ETag
- `/api/_meta/{version,cache_stats,cache_clear}` 三个新端点：
  - `version` → `git_sha / uptime / pid`
  - `cache_stats` → TTL/Redis 双层命中率
  - `cache_clear?scope=ttl|redis|all` → 运营救火按钮
- 引入 `_normalize_quote()` 字段归一化层，统一腾讯/东财/THS 三家字段名（最新价→price、涨跌幅→change_pct、市盈率-动态→pe、市值 元→亿）

### 验证
```
10/10 股票 API 测试 200 OK + 字段齐全
600519/000001/601318/300750/688981/002747/000524/002185/600036/300059
```

## 三、第 3 轮 · app.js 代码组织重构

**目标**：去掉所有 inline `onclick`，引入全局事件委托 + 模块化命名空间。

### 改动
- 在 document 顶层注册一次 click 委托，根据 `data-action` 路由分发
- `action` 支持 `:` 分隔参数（例：`data-action="open-stock:600519"`）
- 替换所有 inline `onclick="fnName()"` 为 `data-action="fnName"`，HTML 与 JS 完全解耦
- 新增 `qGet(q, ...keys)` 字段回退访问助手 — 在多源数据时按顺序尝试字段别名
- 把 `_showLoading/_hideLoading` 引用计数化（支持并发调用）
- 把全局 toast 改为 FIFO 队列 + 自动 drain

### 验证
```
DOM 搜索 onclick="…" = 0 命中
ESLint: 0 errors, 0 warnings
```

## 五、第 5 轮 · 个股 stock 页深度优化

**目标**：把行情+技术+资金+龙虎+情绪+AI 6 个层次组织成可扫读的信息流。

### 改动
- **行情 bento**：价格大字号 + 涨跌色 + 振幅/量比/换手/PE/PB/市值/总股本 8 块卡片，PB 卡片新增（之前缺失）
- **技术面区**：5/10/20/60 日均线 + MACD + KDJ + RSI + BOLL 5 个信号 chip，达标绿色、未达标灰色
- **资金面**：超大单/大单/中单/小单 四色堆叠条 + 净额数字
- **龙虎榜**：若当日上榜，按"机构 / 北向 / 游资 / 拉萨天团" 4 组拆分，Top 5 + 备注（炸板/烂板/极度活跃）
- **AI 分析卡片**：3-6 条要点，每条带置信度 chip
- **限价规则智能切换**：主板 ±10%、创业板/科创板 ±20%、北交所 ±30%、ST ±5%，自动用昨日收盘价算涨停价
- **PE/PB 渲染健壮化**：通过 `qGet` 支持 `pe / 市盈率-动态 / 市盈率(动)` 三种字段名，再也不显示"亏损/暂无"

### 验证
- 688981 中芯国际（科创板）：±20% 限制识别正确，行情/技术/资金/AI 6 区全亮
- 300750 宁德时代：`r9-stock-300750.png` 显示 PE/PB 正常、价格大字号突出
- 300059 东方财富：涨跌停价 ±10% 正确触发

## 六、第 6 轮 · 龙头 dragons 页强化

**目标**：把"情绪→主线→龙头→决策"4 步流水线视觉化、决策可执行化。

### 改动
- **STEP 1 整体情绪**：3 卡片（涨停数 / 最高连板 / 连板梯队）
- **STEP 2 主线 Top 5**：每条带 `流#N / 幅#M` 双排名徽章，主线可点击直接跳个股
- **STEP 3 龙头候选 Top 10**：
  - 6 维评分条形图（连板 30 + 资金 30 + 封成比 20 + 市值 15 + 技术 18 + 题材 15）
  - Top 3 卡片金色顶边（rank-top3 类）
  - 风险标签：炸板/烂板/换手>10% 极度活跃

- **失败回退**：如果 92 只评分失败，显示"龙头评分暂不可用"+ 退化到 Top 30 涨停列表

### 验证

## 八、第 8 轮 · 错误处理 / Toast / Skeleton

**目标**：把"看起来 200 OK 但其实一直在转"的迷惑体验彻底干掉。

### 改动
- **Top Loading Bar**：顶部 2px 渐变进度条 + shimmer 动画，引用计数保证多个并发请求并存
- **Toast 队列**：FIFO + 自动 drain，连点 5 次刷新也只挤掉旧的
- **Toast 类型**：info/success/warning/error，分别配色
- **Skeleton**：每个视图的"等待中"状态都有占位骨架，不再空白闪烁
- **错误兜底**：上游失败 → 显示降级数据 + 原因徽章，而不是 500 空白

### 验证
- 网络断开后再恢复：loading bar 正确显示/隐藏
- 连点刷新按钮：toast 队列按顺序展示不重叠

## 十、第 10 轮 · 10 轮优化整体回顾

### 10 轮核心收益

| 维度 | 第 1 轮 | 第 10 轮 |
|------|---------|---------|
| 上游超时兜底 | 25s 静默挂起 | 显式 timeout + 降级 + 原因徽章 |
| 字段一致性 | 3 家源字段混乱 | `_normalize_quote` 统一 + 单位换算 |
| UI 事件处理 | inline `onclick` × 27 | 全局 `data-action` 委托 |
| Toast | 单实例互相覆盖 | FIFO 队列 + 自动 drain |
| Loading 反馈 | 无 | Top bar + shimmer + 引用计数 |
| 信息密度 | 列表平铺 | Bento 网格 + RANK 徽章 + 多维 chip |
| 美学对比度 | 浅色模式偏暗 | 深/浅双主题 WCAG AA 达标 |
| 决策可执行性 | "看看就好" | 4 步流水线 + 3 桶决策建议 |
| 健壮性回归 | streak_history 崩溃 / AI 卡函数丢失 | 全修复 + 启动期自检 |
| 测试覆盖 | 0 自动化 | 10 股票 × 6 视图端到端 |

### 借鉴的顶级框架/设计模式

| 借鉴 | 来源 | 应用 |
|------|------|------|
| Field normalization layer | Eloquent / SQLAlchemy | `_normalize_quote` 多源归一化 |
| Event delegation | jQuery on() → 现代原生 | `data-action` 全局委托 |
| Skeleton loading | YouTube / Facebook | 6 视图骨架占位 |
| Toast queue | Ant Design / Material UI | FIFO + drain |
| Server-Sent Events | Stripe / Vercel | 调优进度实时推送 |
| TTL + Redis 双层缓存 | Redis 官方推荐 | cache_stats 双命中率监控 |
| bento 网格 | Apple iOS 14+ / Linear | 行情/技术/资金卡片化 |

### 文件改动汇总

| 文件 | 改动量 | 摘要 |
|------|--------|------|
| `web/server.py` | +520 / -180 | `_normalize_quote` + 3 个 meta 端点 + 超时加固 |
