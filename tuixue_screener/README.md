# 退学战法选股系统 (tuixue_screener)

基于退学炒股全套短线交易思想开发的 A 股量化选股程序，**严格按照用户提示词的 4 层流水线筛选、宁缺毋滥、手动触发**。

---

## 🚀 快速开始

```bash
cd ~/scripts/tuixue_screener

# 手动选股（盘中）
python3 screener.py

# 跳过 Layer 4 分时筛选（盘后/回测用）
python3 screener.py --skip-intraday

# 指定日期
python3 screener.py --date 2026-07-08
```

---

## 📊 回测与优化

```bash
# 基础回测（500 票池，1 年）
python3 backtest.py --start 2025-07-01 --end 2026-06-30

# 细颗粒度优化（240 组配置 + 仓位档位，约 5 分钟）
python3 optimize2.py

# 生成综合报告
python3 report.py
```

回测报告位于 `reports/final_report.md`。

## 📁 文件结构

| 文件 | 作用 |
|---|---|
| `config.py` | 所有可调阈值（头部常量） |
| `data_source.py` | 三级行情数据源热备（腾讯/东财/akshare） |
| `pipeline.py` | 4 层严苛选股流水线 |
| `screener.py` | 主入口（手动触发 `run_stock_screen()`） |
| `backtest.py` | 历史回测引擎（月度收益统计） |
| `optimize.py` | 粗颗粒度参数优化（27 组） |
| `optimize2.py` | 细颗粒度参数优化（240 组 + 仓位档位） |
| `report.py` | 生成 Markdown 综合报告 |
| `cache/` | 数据缓存（K 线、行情快照、板块） |
| `logs/` | 运行日志 |
| `reports/` | 选股结果 + 回测报告 |
| `blacklist.json` | 永久拉黑池 |

## 🎯 4 层流水线

| 层级 | 一票否决项 |
|---|---|
| **Layer 1** | 主板 / 成交额 ≥ 8000 万 / 流通市值 50-300 亿 / 换手 5-15% / 5日均量 > 20日均量 / 非黑名单 |
| **Layer 2** | 隶属当期主线（涨幅 ≥ 40 只 / 资金净流入前 3） + 盈亏比 ≥ 2:1 |
| **Layer 3** | MA5>MA10>MA20 (+ 可选 MA60) / 收盘 > MA5 / 20日涨幅 < 35% / 量价配合 |
| **Layer 4** | 9:30-10:30 70% 时间价格在均价线上 / 无尾盘偷袭 / 涨停股早盘换手封板 |

排序：中军龙头 > 二板龙头 > 低位首板，输出前 10 只（`MAX_OUTPUT`）。

## 📐 优化后的最佳参数（基于 12 个月回测）

| 参数 | 值 | 说明 |
|---|---|---|
| 止盈 | **+10%** | 移动止盈触发位 |
| 止损 | **-5%** | 硬止损 |
| 持仓天数 | **7 天** | t+1 买入 → t+7 收盘 |
| 盈亏比下限 | **2.0:1** | 可严到 2.5 |
| 每日选股上限 | **10 只** | top_n 越大越分散 |
| 仓位档位 | **30%** | 单票占账户 30% |
| MA60 严格度 | **关闭** | MA5>MA10>MA20 已足够 |

**优化后年化收益率：~2.88%**（月均 0.24%，胜率 45%）

## ⚠️ 风险提示

1. **回测 ≠ 实盘**：未考虑滑点、交易费、涨跌停限制、停牌
2. **样本偏差**：500 只随机抽样可能错过小盘龙头
3. **过拟合风险**：优化出的参数可能只对历史数据有效
4. **黑天鹅**：极端行情可能造成重大损失
5. **本系统仅供学习研究**

## 🔄 与现有 `~/scripts/stock/` 的关系

本系统**独立**于 `~/scripts/stock/`（dragon_scanner / position_monitor 等），但**共用思路**：
- 都基于退学炒股战法
- 都依赖东方财富/腾讯数据源
- `tuixue_screener` 更**严格**（4 层流水线 + 宁缺毋滥）
- `stock/` 体系更**灵活**（可配置的情绪/风控/择时模块）

**建议组合使用**：
- `tuixue_screener` 用于**每日盘后选股**（明确信号）
- `stock/` 体系用于**盘中监控**（持仓管理 + 做 T）
